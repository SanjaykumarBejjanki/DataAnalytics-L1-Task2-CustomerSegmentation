# Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project performs customer segmentation using Machine Learning.

The goal is to group customers based on their:

- Age
- Annual Income
- Spending Score

K-Means Clustering is used to identify different customer groups and understand their purchasing behavior.

## 🎯 Objectives

- Explore and understand customer data
- Analyze customer demographics
- Visualize Annual Income and Spending Score
- Determine the optimal number of clusters using the Elbow Method
- Apply K-Means Clustering
- Analyze customer segments
- Visualize the distribution of different customer groups

## 📊 Dataset

The dataset contains 200 customers with the following columns:

| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| Genre | Customer gender |
| Age | Customer age |
| Annual Income (k$) | Annual income in thousands of dollars |
| Spending Score (1-100) | Customer spending score |

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning

K-Means Clustering was used for customer segmentation.

The Elbow Method was used to determine the appropriate number of clusters.

### Customer Segments

The project identifies the following customer groups:

- High-Value Customers
- High-Income Low-Spending Customers
- Low-Income Low-Spending Customers
- Young High-Spending Customers
- Other customer groups based on clustering results

## 📈 Visualizations

The project includes:

1. Annual Income vs Spending Score
2. Elbow Method
3. Customer Clusters
4. Segment Distribution
5. Gender Distribution by Segment
